CC 音乐播放器 · 转换工具说明
================================

这个文件夹里的文件要放在一起，别单独拿一个走：

  convert.bat       Windows 用：把音乐文件夹拖到它上面
  convert.js        转换器本体（Mac / Linux 也可以直接用）
  dfpwm-encode.js   PCM -> DFPWM 编码器（转换器会自己调用）

--------------------------------------------------------------
使用前先装两样东西
--------------------------------------------------------------

  1. Node.js      https://nodejs.org          （选 LTS 版本）
  2. ffmpeg       https://ffmpeg.org/download.html
     Windows 也可以直接： winget install --id Gyan.FFmpeg

装完可以打开命令行验证一下：

  node -v
  ffmpeg -version

（如果 ffmpeg 找不到，也可以把 ffmpeg.exe 直接放到这个文件夹里，
  转换器会优先用它。）

--------------------------------------------------------------
怎么用
--------------------------------------------------------------

Windows：
  把装着歌曲的文件夹直接拖到 convert.bat 上，等它跑完。

Mac / Linux：
  node convert.js /你的音乐文件夹

转换器会：
  * 只取第一条音频流（自动忽略封面图、字幕）
  * 统一成 48 kHz / 单声道 / 8 bit
  * 在同目录生成同名 .dfpwm
  * 已经转过且比源文件新的会跳过（想强制重转加 --force）

支持格式：mp3 / flac / aac / m4a / wav / ogg / opus / wma

--------------------------------------------------------------
转换完成后
--------------------------------------------------------------

把生成的 .dfpwm 文件复制进 CC 电脑的 music 目录：

  saves/<世界名>/computercraft/computer/<电脑ID>/music/

然后游戏里对着播放器按 r 重新扫描（或者 reboot 电脑）。

注意：文件名建议只用英文/数字。日文、俄文等字符在部分环境下
会被 CC 的文件系统变成 "?"，那首歌就会打不开。想显示好看的
名字，写 music/names.txt：

  song_01=Одна (АДЛИН)
  song_02=夜に駆ける

--------------------------------------------------------------
常见问题
--------------------------------------------------------------

Q: 双击 convert.bat 一闪就没了？
A: 多半是没装 Node.js，或者路径里有中文/特殊字符。在命令行里
   手动运行能看到具体报错：
   node convert.js "你的音乐文件夹"

Q: 提示 ffmpeg not found？
A: 把 ffmpeg.exe 放到这个文件夹，或者把它的 bin 目录加进 PATH。

Q: 转换出来的 .dfpwm 只有几 KB？
A: 说明源文件基本没声音或者解码失败，用播放器打开源文件确认一下。

Q: 音质怎么像收音机？
A: DFPWM 是 1 bit 编码，本来就这样。可以先用 -af loudnorm 压一下
   响度再转，会好一点。
