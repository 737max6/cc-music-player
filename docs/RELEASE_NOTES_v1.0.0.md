# 🎵 播放器 v1.0.0

第一个能用的版本。

## 这个版本有什么

  * 显示屏 UI：点歌、底部 `[上首] [停止] [下首]`、右侧滑条
  * 键盘：`↑` `↓` 选歌、`回车` 播放、`空格` 停止、`←` `→` 切歌、`+` `-` 音量、`r` 重扫
  * 开机自动播放，播完循环，可开随机
  * 多个扬声器同时播放（各自投喂，不会重复）
  * 流式解码：每次只读 16 KB，几百首歌也不占内存
  * `names.txt`：文件名和显示名分开，显示中文/日文都行

## 下载哪个？

  * `music.lua` —— 播放器本体，放进电脑文件夹
  * `startup.lua` —— 开机自动启动
  * `Converter.zip` —— 电脑端的转换工具，解压后照里面的 `说明.txt` 做
    （需要 **ffmpeg** + **Node.js**）

## 装之前

  1. **CC: Tweaked 1.100 或更高**
  2. **必须**装 [CC UTF-8 Compat](https://github.com/Kondrashka177/CC-UTF8-Compat)，
     不然中文全是问号
  3. 至少一个扬声器

## 怎么放歌

把装歌的文件夹拖到 `convert.bat` 上，转出来的 `.dfpwm` 丢进电脑的 `music/`
目录，游戏里对着播放器按 `r`。
